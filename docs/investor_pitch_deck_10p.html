2. 痛点与机会

痛点

  • 线下反馈慢，线上难纠偏；动作难量化与复现。
  • 教练时间碎片化，难以规模化服务更多学员。

机会

  • 体育/技能训练线上化，用户愿为“可见进步与认证”付费。
  • 机构数字化转型需要“效果量化”的基础设施。

4. 技术路线与可解释评分

  • 关键点提取 → 角度/速度/稳定性等特征 → 规则 + 学习的混合评分引擎。
  • 可解释：角度区间、稳定性、对称性，骨架与角度叠加可视化。
  • 个性化：基于学员“难点图谱”的下一步训练建议。
